# SIMORGH Release Signoff

A release is **NOT APPROVED** unless the human maintainer explicitly changes every required item from `PENDING` to `VERIFIED` and records the target commit/tag.

## Engineering

- PENDING: clean checkout succeeds
- PENDING: minimal dependency install succeeds
- PENDING: full test suite succeeds
- PENDING: runtime audit succeeds
- PENDING: repository hygiene succeeds
- PENDING: adversarial/security suite succeeds
- PENDING: external-bind authentication test succeeds
- PENDING: SBOM generated for exact release environment

## Rights and compliance

- PENDING: every shipped data/model/content asset has a verified provenance and redistribution record
- PENDING: third-party dependency license inventory reviewed for exact release versions
- PENDING: privacy/data-flow documentation matches executable behavior
- PENDING: target jurisdiction pack reviewed
- PENDING: prohibited/high-risk use policy reviewed
- PENDING: public claims reviewed against evidence
- PENDING: incident/vulnerability disclosure process verified
