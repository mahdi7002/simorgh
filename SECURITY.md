# Security Policy

## Reporting a vulnerability

If you find a security issue (e.g. a way to leak local file paths, execute
arbitrary code via an API endpoint, or bypass the content-safety layer for
Quranic/religious text generation), please **do not open a public issue**.

Instead, email: mahdijafarinajafabadi@gmail.com with:
- A description of the issue
- Steps to reproduce
- Potential impact

Expect an initial response within a few days. This is a solo-maintained
project, so response time may vary.

## Scope
This applies to the code in this repository. It does not cover the
private SimorghCore development environment or unpublished datasets.
