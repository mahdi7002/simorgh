## برای بازدیدکننده

سلام.

این مخزن مال یک آزمایش «چه می‌شود اگر فقط prompt بنویسیم» نیست و مال ادعای «جایگزین ChatGPT» هم نیست.

سیمرغ از این سؤال آمده: **اگر محدودیت رم، آفلاین بودن، و هویت فارسی را جدی بگیریم، چه سیستمی می‌ماند؟**

پاسخ امروز: یک هستهٔ قابل‌اجرا، پرسوناهای نام‌دار، و سندی که می‌گوید از کجا آمده‌ایم و چه چیزی هنوز کامل نیست.

اگر Local LLM، فرهنگ ایرانی، یا پروژه‌های یک‌نفرهٔ صادق برایتان جذاب است — README را بخوانید، `demo/` را اجرا کنید، و اگر خواستید Issue باز کنید. اگر فقط دنبال بنچمارک میلیاردپارامتری هستید، اینجا جای آن مسابقه نیست؛ و این را با افتخار می‌گوییم.

با احترام،  
نگهدارندهٔ پروژه و مسیر هدایت‌شدهٔ سیمرغ
