## Decisions

- No current bibliographic entry in the six-item paper bibliography failed the official-record/abstract check, so none was removed in this pass.
- The Geifman & El-Yaniv reference now points to the official NeurIPS proceedings page rather than relying only on arXiv.
- The current poster proposal `DH2027_POSTER_PROPOSAL_EN.md` still contains a literature placeholder and no completed reference list. It is explicitly marked not submission-ready; the placeholder is not treated as a verified citation.
- Citation existence is not the same as having read the full paper. The two paper drafts already disclose that full-text review and venue-specific formatting remain required. Before final submission, read the relevant sections in full and tighten claims to the passages actually used.
- None of these literature fetches verifies SIMORGH dataset provenance, redistribution rights, clean-clone reproducibility, or the performance of the new 40-question benchmark. Those remain separate gates.
