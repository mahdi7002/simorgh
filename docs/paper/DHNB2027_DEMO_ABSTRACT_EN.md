# DHNB 2027 poster/demo abstract draft (conditional, not submitted)

**Working title:** Making the Source Visible: A Local Persian Knowledge Interface for Cultural Memory  
**Track:** General track, poster/demo; alternatively Works-in-Progress if a feedback question is explicitly requested  
**Status:** Draft only. Submit only after a short live run, reference check and data-display rights review.

## Abstract (approximately 350 words)

Generative AI interfaces can make cultural knowledge easy to ask about while making the path from a question to its source difficult to inspect. This matters for Persian literary heritage, where a fluent answer may conceal ambiguous authorship, incomplete records or a model-generated claim that should not be treated as evidence. Digital humanities therefore needs demonstrations that make not only the answer, but also the source, uncertainty and limits of a digital method visible.

This poster/demo presents SIMORGH as a work in progress: a locally operated Persian knowledge interface that combines SQLite/FTS retrieval with a small language model and a separate deterministic route for some verse-attribution questions. It is not presented as a proven general-purpose truth system. Its interaction design distinguishes a result retrieved from a collection from text subsequently generated by a model; for verse attribution, the lookup can return an answer, an ambiguous result or an abstention rather than always naming a poet. Ordinary Quran, poetry and book retrieval can instead be inserted into a model prompt, so those responses must not all be described as model-independent.

The proposed demonstration has three brief, inspectable steps: (1) ask who wrote a familiar Persian verse and inspect the attribution path; (2) ask a question that can retrieve a local passage and examine the source label; and (3) ask for information deliberately absent from the available collection, then examine whether the interface acknowledges missing evidence. A conceptual architecture diagram will show the boundary between retrieval, deterministic attribution and model-generated response. The source repository and evaluation protocol will be linked so participants can inspect the method rather than rely on a promotional video alone.

The research question is modest: how can an interface help visitors distinguish stored cultural evidence from generated interpretation when using a locally operated language tool? Prior work on retrieval-augmented generation motivates explicit access to external evidence (Lewis et al., 2020), while Persian LLM evaluation benchmarks highlight the importance of task-specific, culturally relevant assessment (Abaskohi et al., 2024). SIMORGH's current quantitative evidence is limited to historical, database-derived verse-attribution tests on one machine. Its new 40-question, two-model benchmark has not yet been run, and the clean-clone availability and redistribution rights of parts of the underlying poetry and translation data remain unverified. The demo will disclose these limits and display only data approved for public presentation.

The intended discussion is with digital-humanities researchers, librarians, language technologists and cultural-heritage practitioners: what provenance cues are useful, how should ambiguous attribution be represented, and what does local execution solve or leave unresolved?
